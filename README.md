# Introspection

**Titel:** Introspection  
**Technik:** Öl auf Leinwand  
**Größe:** 140 × 100 × 4,5 cm  
**Jahr:** 2025  
**Preis:** € 4.300

## Bildbeschreibung

Das Werk zeigt ein überdimensionales Haupt, dessen innerer Bereich durch ein herausgelöstes Fragment geöffnet wird.

Der Ausdruck des Schreis kontrastiert mit den stillen gleichförmigen Köpfen, die den unteren Bildraum füllen.

Eine einzige Figur blickt aus der Menge und gewinnt individuelle Präsenz.

Die Komposition verdeutlicht den Spannungsbogen zwischen innerer Zerrissenheit und äußerer Gleichförmigkeit.

"Introspection" verweist auf den Prozess der Selbstbefragung und das Ringen um Authentizität innerhalb einer homogenen Masse.
